## Reporting a Vulnerability

We take the security of MZSAE seriously. If you discover a security vulnerability within this project, please report it via our responsible disclosure process.

### Scope
**In Scope:**
* Metal kernel memory safety issues
* Buffer overflows or out-of-bounds reads/writes in the C++ runtime
* Vulnerabilities in project dependencies

**Out of Scope:**
* Numerical accuracy issues or precision degradation (please open a regular GitHub issue for these)
* Bugs in the CPU reference backend that do not present a security risk

### Process
1. Email your report to `security@mzsae.dev` or the author's email.
2. We will acknowledge receipt of your vulnerability report within 48 hours.
3. We ask that you adhere to a 90-day disclosure window. We will endeavor to provide a patch or mitigation within this timeframe before public disclosure.
