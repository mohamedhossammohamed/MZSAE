The problem

Every token pays for the whole past.

At batch size one, attention has an arithmetic intensity of roughly one to two FLOPs per byte. The silicon waits; the bus saturates. Quantizing the KV cache does not rescue you — the ALU cost of dequantization cancels the bandwidth you saved.

The only durable win is refusing the read. But skipping blocks blindly destroys retrieval. So the question is not how to compress memory. It is how to know, cheaply and provably, that a block cannot matter — before touching it.

decode step, 128k context ───────────────────────── dense SDPA 134.2 MB read MZSAE selective 2.0 MB read ───────────────────────── sentinels evaluated in L2 payload fetched only if U_b ≥ m_local − τ
The mechanism

Three ideas, composed.

01

Plane-2 sentinels

RoPE is decoupled into fast positional and slow semantic manifolds. Each 64-token block leaves a 64-byte sentinel in L2. A tight Cauchy–Schwarz bound is evaluated in registers; irrelevant blocks branch past the DRAM fetch entirely.

U_b = (⟨q_s, s_s⟩ + ‖q_s‖·R_Δ + C_f) / √d
02

Dual-plane cache

Approved blocks live as centroid plus 2-bit residuals — the same coarse-anchor, fine-detail instinct as NVFP4 — rebuilt in registers at use. The compressed form travels; the full form exists only for a moment.

K ≈ μ + Δ, Δ ∈ 2-bit, μ ∈ FP16
03

Biological eviction

An orbitofrontal value MLP scores block survival; an ACC-style directional veto protects semantically aligned blocks from greedy eviction; a hippocampal ring buffer replays transitions offline via TD(0) during idle cycles.

V(s) ← r + γ·V(s′), veto if cos θ_slow > 0.40

01 · Quickstart & Integration Guide

The MZahran Sparse Attention Engine (MZSAE) is a hardware-aware sparse continual attention runtime that eliminates the KV-cache memory wall during long-context LLM inference.

Installation

# Direct package install (PyPI / wheel)
pip install mzsae

# Or install from source with Metal C-extensions compiled
git clone https://github.com/mohamedhossammohamed/MZSAE.git
cd MZSAE
make
pip install -e .

1. PyTorch Drop-in Module (MZSAEAttention)

Drop-in replacement for standard multi-head attention and grouped-query attention layers:

import torch
from mzsae import MZSAEAttention

# Initialize module with automatic hardware profiling
attn = MZSAEAttention(
    embed_dim=2048,
    num_heads=16,
    num_kv_heads=4,
    hardware_profile="auto"  # Auto-detects Apple M1..M4 or CUDA
)

# Standard attention call: [batch, seq_len, heads, head_dim]
out = attn(q, k, v, causal=True)

02 · Architectural Core & Dual-Plane Cache

Standard attention mechanisms treat the KV cache as a monolithic contiguous DRAM buffer. In contrast, MZSAE implements a biologically-inspired dual-plane memory hierarchy:

Plane-1: DRAM Compressed Payload

Full Key and Value activations quantized into 2-bit affine residual blocks aligned to 128-byte cache lines. Read selectively on demand.

Plane-2: L2-Resident Sentinels

Compact 64-byte centroid descriptors cached in fast on-chip SRAM/L2. Evaluated in GPU registers to verify block relevance before DRAM reads.

Cauchy–Schwarz Upper Bounding

To determine if an evicted or un-streamed block in DRAM can impact attention logits, MZSAE evaluates a provably tight Cauchy–Schwarz upper bound on the dot product:

U_b = (⟨q_s, s_s⟩ + ‖q_s‖ · R_Δ + C_f) / √d

If $U_b < m_{\text{local}} - \tau$, the block's Plane-1 payload is guaranteed to contribute insignificantly to the softmax denominator. The GPU branches past the DRAM bus transaction entirely.

03 · RoPE Manifold Decoupling

Rotary Position Embeddings (RoPE) rotate Key vectors based on absolute token position. Naive sparse attention fails because high-frequency rotations cause norm estimates to oscillate unpredictably across temporal positions.

Frequency Decoupling Strategy

MZSAE bifurcates the embedding channels into two orthogonal manifolds:

  • Slow Semantic Manifold (Dimensions 112–127): Quasi-static positional frequencies that preserve semantic alignment for sentinel dot products and directional veto gating.
  • Fast Positional Manifold (Dimensions 0–111): Rapidly rotating dimensions bounded by maximum circular radius $C_f$, guaranteeing positional safety without distorting magnitude bounds.
# Decoupling split enforced across all heads
Dim_RoPE     = {112 ... 127}  # Slow manifold (semantic anchor)
Dim_Semantic = {0 ... 111}    # Fast manifold (bounded radius)

04 · Neuromorphic Eviction Policy & TD(0)

Rather than using crude First-In-First-Out (FIFO) or recency truncation, MZSAE orchestrates cache eviction through a three-stage biological control loop:

Brain RegionMZSAE ComponentOperational Invariant
Orbitofrontal Cortex (OFC)TDAttnPolicy (27k MLP)Estimates expected future retention value via Temporal Difference TD(0) reinforcement learning.
Anterior Cingulate (ACC)DirectionalVetoHard cosine threshold ($\cos \theta_{\text{slow}} > 0.40$) preventing eviction of semantically crucial tokens.
HippocampusTelemetryRingBufferCircular replay buffer recording cache hit/miss transitions for background consolidation.

Temporal Difference Learning Rule

V(s) ← V(s) + α [ r + γ · V(s′) − V(s) ]

The value network continuously learns which temporal blocks correlate with downstream answer generation, maintaining 100% NIAH accuracy under strict 2,048-token physical limits.

08 · Red-Team Audit & Limitations

In accordance with empirical research standards, MZSAE establishes clear boundary conditions where sparse attention trade-offs must be acknowledged:

  • Short-Context Crossover (<2,048 tokens): Below ~2k context, standard dense attention is faster. Pass-0 sentinel estimation represents pure overhead until the memory bus saturates.
  • DRAM Gating Telemetry: Reported DRAM reductions are derived from kernel-observed block prune counts ($1 - \text{approved}/\text{total}$), not direct hardware current sensors.
  • Needle Dilution Invariance: Synthetic RoPE beacon needles achieve 100% retrieval. However, semantic needles whose vector norms match background noise can suffer from attention logit dilution.

Read the complete technical red-team report in docs/LIMITATIONS.md.

Known limits

What we will not overclaim.

Read this before benchmarking us.

Below ~2k context, dense attention is faster — the sentinel pass is overhead until the memory wall bites. Our DRAM figures are estimates from kernel-observed prune counts, not powermetrics counters. Needles with background-level magnitude but perfect alignment dilute across approved blocks: the failure mode is attention dilution, not eviction loss. Architecture tests prove shape and routing invariance on synthetic tensors, not semantic correctness on trained weights. Every boundary above, with raw numbers, lives in docs/LIMITATIONS.md.
